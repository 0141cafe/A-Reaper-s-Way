# 死神の流儀 / A Reaper's Way

現代日本のベッドタウンにある小さな葬儀社を舞台に、死期の近い人々を観察するために人間界へ来た新人の死神を描く。個々の死と、その前にあった日常を数話完結で重ね、主人公自身の人格が変化していく長い物語につなげる。

- **舞台**：埼玉県南部のベッドタウン（架空の南戸田駅、モデルは戸田公園駅周辺）。小規模葬儀社「河辺葬祭」、駅前通りの「Cafe Minamo」、主人公とヒロインが暮らす「はすみ荘」。
- **形式**：連作短編的な構成と、主人公の変化を追う長編の縦軸の組み合わせ。
- **主題**：死を観察するなら生きていた時間も見なければならない／当たり前の日常のかけがえのなさ／観察者もまた観察され、関わりの中で変わる。
- **方向性**：天界の陰謀や派手な事件ではなく、普通の葬儀社の日常と個々の人生を中心に据える。天界の上位存在を単純な悪役にはしない。
